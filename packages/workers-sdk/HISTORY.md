# Workers SDK history

Wrangler 4.153.0 incorporated [PR #15846](https://github.com/cloudflare/workers-sdk/pull/15846), merge a88cac4d880629a4ad68f7173b3353941bea6081, with an explicit Bun rejection. The local capability regression first rejected 503 instead of 200, then passed local HTTP, direct dispatch, replacement/unregistered-fetch rejection and shutdown after the independent verified-fetch patch.

The 4.153.0 fork head [1c0977d](https://github.com/iki/workers-sdk/commit/1c0977d2f5485af9a65562f8fafeaa6b3a4124de) was superseded by the recorded 4.158.0 version, preserving guard semantics. [Availability discussion](https://github.com/cloudflare/workers-sdk/issues/15717#issuecomment-6453015355) and [4.158.0 follow-up](https://github.com/cloudflare/workers-sdk/issues/15717#issuecomment-6685718214) retain observed results. Upstream declined Bun support; no duplicate PR was opened.

The reviewed [PR #16645](https://github.com/cloudflare/workers-sdk/pull/16645) was closed/unmerged; its bundler interception conflicts with external Undici imports. It does not replace the verified adapter. Statuses are source observations through 2026-11-06.

## November 20, 2026

Wrangler 4.165.0 and Miniflare 5.20261118.0-beta retain the Bun guard. The 4.158.0 bundle did not apply to the rebuilt CLI. With Undici 8.13.0 and both prerequisite preloads on Bun 1.4.2 (Windows x64), the pristine package returned HTTP 503 where the local harness expected 200. Separate frozen Aube 2.5.1 installations verified the pristine and patched cases with dependency lifecycle scripts disabled. [Release](https://github.com/cloudflare/workers-sdk/releases/tag/wrangler%404.165.0) · [Earlier 4.158.0 fork](https://github.com/iki/workers-sdk/commit/31806d8588cfe225f499474c90c42736733488ce)

The versioned patch returned HTTP 200 and both direct dispatch routes returned the worker body. Replacing the registered fetch during a run caused direct dispatch to reject. Starting with a replaced or unregistered fetch preserved HTTP 503 and rejected both direct routes. Each harness closed. The separate source predicate test passed with Node 24.22.3. Upstream's full suite and a consumer's D1 lifecycle remain unverified. [Package matrix](../../docs/regressions.md)

The 2,252-byte ordered bundle has SHA-256 `d044b7020ffc42153fe9e1e8371d3321575d1dcc4a217ff00bf7252c912e15b7`. The catalog applicability check applied it to the verified npm archive and reversed it, restoring the published CLI's SHA-256 `c99aa5c2c491f32fe2cd8b42181f2a5553626e96e51251204dc70c3271845a03`. ## 2026-11-28

The web profile moved to Wrangler 4.169.0, Miniflare 5.20261127.0-beta and Undici 8.14.0 on Bun 1.4.5 for Windows x64. The 4.165.0 patch applied with shifted hunk positions. Regenerating it against the published 4.169.0 CLI produced a 2,252-byte bundle with SHA-256 `43b60f0373204af06655431874acf9e2932c30f29545e428f53da3baee661877`. Applying and reversing it restored the published CLI SHA-256 `c695f459d5b998cf44f28874a4fe7878cee4d7263970ed90141ca0f2ce6d6ac3`. [Published archive and integrity](https://registry.npmjs.org/wrangler/4.169.0) · [Release source](https://github.com/cloudflare/workers-sdk/commit/370ea36c3b25414b7ee521238db8cbd54e19e522) · [Installable bundle](../../patches/wrangler@4.169.0.patch)

Separate Aube 2.11.0 frozen installations ran the real Worker harness with both preloads. The published CLI returned HTTP 503 with the registered fetch. The patched CLI returned HTTP 200 and both direct routes returned the worker body. Replacing the fetch during a run made direct dispatch reject. Starting with a replaced or unregistered function preserved HTTP 503 and rejected both direct routes. Each harness closed. Application-level Worker/D1 acceptance remains outstanding. [Regression procedure](../../docs/regressions.md) · [Local harness](adapters/wrangler-local.test.mjs)
